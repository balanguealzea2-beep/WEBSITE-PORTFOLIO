My Projects

Automatic Street Light Using Light Dependent Resistor (LDR) + One

This project is an Arduino-based automatic lighting system that uses a Light Dependent Resistor (LDR) to detect the amount of light in the surroundings. The system can automatically control a light depending on whether the environment is bright or dark.

My Role: I worked on assembling the components, connecting the circuit, and programming the Arduino Uno to respond to changes in light intensity.

Technologies & Tools: Arduino Uno, LDR, LED, resistors, jumper wires, and Arduino IDE.

Traffic Light Control System

This project is an Arduino-based traffic light system designed to simulate how traffic signals operate. The system uses different LEDs to represent the red, yellow, and green traffic lights and follows a programmed sequence.

My Role: I helped assemble the circuit, connect the LED components, and create the program that controls the timing and sequence of the traffic lights.

Technologies & Tools: Arduino Uno, red LED, yellow LED, green LED, resistors, jumper wires, and Arduino IDE.

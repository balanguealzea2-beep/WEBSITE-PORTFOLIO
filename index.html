Application of IT111 Concepts

Module 1: Evolution of Computing

Computing has evolved from large and limited machines into smaller, faster, and more accessible devices. This has greatly influenced the IT field by making tasks such as programming, website development, communication, and data management easier and more efficient.

Module 2: Computer Systems

A computer system works through the combination of hardware, software, data, people, and procedures. For example, when creating a website, I use computer hardware and software to write and run code, while people and procedures help determine how the system is used.

Module 3: Connected Computing

Connected computing allows information to travel between devices through networks and the Internet. Websites are an example of this because users can access information stored on other computers through an Internet connection.
